# 出貨系統上線步驟（給黃小姐照著做）

畫面和程式碼都已經寫好了，剩下這幾步需要你在自己的 Google 帳號裡操作，
大概 10-15 分鐘。做完把「網頁應用程式網址」給我，我幫你接上去、一起測試。

## Step 1：開啟 Apps Script

1. 打開跟訂購網頁共用的那份 Google 試算表（客人下單資料累積的那份）
2. 上面選單點「擴充功能」→「Apps Script」
3. 會開一個新分頁，裡面預設有一段 `function myFunction() {}`，**全部刪掉**
4. 把 [`apps-script/Code.gs`](apps-script/Code.gs) 這個檔案的內容整個複製貼上進去
5. 找到最上面這一行：
   ```
   const SHARED_PASSWORD = "請改成你們自己的密碼";
   ```
   把引號裡的字改成你們家人要共用的密碼（像 Wi-Fi 密碼那樣，之後開系統都要打這組）
6. 上面工具列點「儲存」（磁片圖示）

## Step 2：部署成網頁應用程式

1. 右上角點「部署」→「新增部署作業」
2. 類型選「網頁應用程式」
3. 「執行身分」選「我」
4. 「誰可以存取」選「所有人」（不是「僅限我」，不然出貨系統開不起來；因為有密碼保護，選「所有人」是安全的）
5. 點「部署」，第一次會跳出「授權存取權限」，照著畫面選你的帳號、點「允許」
6. 完成後會看到一個網址，長得像：
   `https://script.google.com/macros/s/xxxxxxxxxxxx/exec`
7. **把這個網址整個複製，給我**（或直接告訴我，我幫你貼進設定檔）

> 之後如果我又更新了 Code.gs 的內容，你只需要回到這個 Apps Script 分頁，
> 貼上新的程式碼、存檔，再「部署」→「管理部署作業」→ 點選現有的部署 → 版本選「新版本」→ 部署，
> 網址不會變，不用重新給我一次。

## Step 3（可選，之後再做也可以）：讓「每日備料彙總」更準確

出貨系統會自動把客人網頁下的訂單也讀進來，取貨方式（自取/郵寄）已經能自動判斷。
但客人下單的品項/口味明細目前是存成一大段文字，出貨系統沒辦法 100% 準確拆出「每種口味幾顆」，
只有系統自己判斷不出來的部分會歸類成「無結構化明細」。

想讓客人下的單也能精準算進每日備料彙總，需要在 Google 表單多加一題：

1. 打開跟訂購網頁連結的那份 **Google 表單**（不是試算表）
2. 新增一題，類型選「段落」，標題隨便取（例如「明細JSON」），**不用**設為必填
3. 點右上角「預覽」（眼睛圖示），打開瀏覽器開發者工具（按 F12 或右鍵「檢查」），
   找到這一題的 `name="entry.xxxxxxxxx"`，把這串數字代碼記下來
4. 把代碼告訴我，我幫你填進 [`../app.js`](../app.js) 的 `GOOGLE_FORM.entries.detailJson`

這一步不做也完全不影響系統運作，只是客人下的單在「每日備料彙總」裡準確度會差一點，
可以先上線用，之後有空再補。

## Step 4：把網址填進出貨系統

我拿到你給我的網址後，會幫你貼進 [`data.js`](data.js) 的 `FULFILLMENT_API.url`，
然後帶你一起測試「輸入密碼 → 選操作人 → key 一張測試訂單 → 查看每日訂單 → 標記完成」整個流程。
